# Public source-sharing decision

On 2026-10-16 the project owner explicitly approved the clean migration to its own
GitHub repository and chose public visibility. Approval covers intended source
and ordinary CI logs in `dcajacob/gmatpy`, with NASA ancestry and notices retained.
It does not approve paid resources, new credentials/scopes, binary release assets,
PyPI publication, or bypassing applicable restrictions.

This records source-sharing authorization separately from the CSPICE-derived
product release determination. The `owner_decision_required` item in the component
manifest remains open. Final product release evidence must identify exact
source/artifact hashes, producer/jurisdiction, input/contract facts, distribution
scope and the basis for the product determination.
