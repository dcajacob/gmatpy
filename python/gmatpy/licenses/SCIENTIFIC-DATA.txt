Nutation: data/planetary_coeff/NUTATION.DAT
  This is a new numeric-only presentation of the two models implemented
  by GMAT's coordinate transformations: 1980 (106 terms) and 1996 (263
  terms). The unused 1950 and unsupported 2000 sections are not included.
  All argument multipliers and numerical coefficients of both implemented
  models are unchanged. Their deterministic order and headings are generated
  independently by python/tools/generate_coordinate_data.py.

  The 1980 values match ERFA 2.0.1 nut80.c exactly. Preserve the BSD-3-Clause
  notice in ERFA.txt for this component. ERFA is derived with permission
  from SOFA; this is an ERFA-derived table, not an official SOFA release.
    https://github.com/liberfa/erfa/releases/tag/v2.0.1
    https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/nut80.c

  The 1996 values match all 263 luni-solar coefficient records in the
  official IERS Conventions (1996) KSV_1996_3 numerical model listing.
  Only its numerical argument multipliers and coefficient values are
  transcribed. Neither the Fortran algorithm nor explanatory prose is
  included. These functional mathematical model coefficients are the
  scientific-data basis; this is not a claim that all IERS software is
  freely relicensable. Attribution: IERS Conventions (1996), D. D. McCarthy
  (ed.), IERS Technical Note 21, KSV_1996_3 model.
    https://iers-conventions.obspm.fr/conventions_archive.php
    https://iers-conventions.obspm.fr/archive/1996/1996IERSConventionsArchive.tar.gz

ICRF: data/icrf/ICRF_ERFA_Table.txt
  Independently regenerated numerical rotation-vector output using the
  BSD-3-Clause ERFA 2.0.1 reference routines. Preserve ERFA.txt and identify
  this table as a GMAT Py generated table, not an official ERFA/SOFA table.
  It implements the documented transformation through a common terrestrial
  frame between the IAU 1976/1980 FK5 and IAU 2006/2000A ICRF reductions.
  The generator documents the A1/TAI/TT offsets, conventional common
  Earth-rotation phase, radian vector units, signs, and historical
  equation-of-equinoxes convention. No original NASA ICRF vector values
  or external observed EOP values are inputs to this computation.
    https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/c2i06a.c
    https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/pnm80.c
    https://iers-conventions.obspm.fr/content/chapter5/icc5.pdf
  The 51,136 daily rows retain the old date range and fill gaps in its
  sampling grid. This changes small scientific/model/interpolation errors,
  as quantified in the distribution validation report. It is not a claim
  of bit-identical results to the legacy table or perfect physical accuracy.
