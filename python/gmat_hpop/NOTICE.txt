GMAT source: https://github.com/nasa/GMAT
GMAT incorporates NASA/JPL NAIF CSPICE; its code is statically linked into
the engine. Scientific data are the files distributed with this GMAT source
snapshot (EGM96, JGM3, DE405, Earth orientation, time and atmosphere inputs).

Native platform libraries (glibc and the C++ runtime) are supplied by the
host operating system. The legacy SVN data updater and Xerces are excluded.
